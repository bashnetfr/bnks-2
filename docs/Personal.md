# Student Hub MVP Feature Specification

## Overview

Student Hub is a centralized platform for students to discover,
organize, and manage academic and extracurricular opportunities.

Core goals: - Discover hackathons, competitions, workshops, clubs, and
events - Save interesting opportunities - Track applications - Manage
deadlines - Build an achievement profile

------------------------------------------------------------------------

# 1. Student Profile Structure

## Purpose

The student profile is the foundation of personalization.

It stores identity, interests, skills, and activity history.

## Information

### Basic Details

-   Name
-   Profile picture
-   School/college
-   Grade/year
-   Location
-   Email

### Academic Details

-   Education level
-   Field of study
-   Subjects
-   Skills

### Interests

Examples: - Technology - AI - Business - Design - Science - Finance -
Leadership

## Activity Summary

Display:

-   Events attended
-   Applications submitted
-   Saved opportunities
-   Achievements earned

Example:

    12 Events Joined
    5 Applications
    7 Saved Opportunities
    3 Badges

------------------------------------------------------------------------

# 2. Saved Events

## Purpose

Allow students to bookmark events they want to attend.

Examples: - Hackathons - Workshops - Seminars - Competitions - Club
activities

## Features

Students can: - Save events - Remove saved events - Add reminders -
Filter saved events - Sort by date

## Event Card

    AI Hackathon Nepal

    Date:
    September 15

    Location:
    Kathmandu

    Registration:
    Open

    Reminder:
    Enabled

------------------------------------------------------------------------

# 3. Saved Opportunities

## Purpose

A collection of opportunities students want to revisit.

Examples: - Scholarships - Internships - Competitions - Fellowships -
Volunteer programs

## Features

Students can: - Save opportunities - Add notes - Track deadlines - Move
items to applications

## Opportunity Card

    Deadline:
    20 days remaining

    Category:
    Technology

    Saved

# 5. Application Tracker

## Purpose

Help students manage submissions.

## Status Flow

    Interested
    ↓
    Applied
    ↓
    Under Review
    ↓
    Accepted
    ↓
    Completed

## Application Data

-   Organization
-   Opportunity name
-   Deadline
-   Status
-   Notes
-   Submission date

Example:

    AI Challenge

    Status:
    Applied

    Deadline:
    August 30

    Notes:
    Waiting for response

# 6. Event Calendar

## Purpose

A timeline of important activities.

Includes: - Saved events - Deadlines - Workshops - Competitions

Views: - Monthly - Weekly - Upcoming list

------------------------------------------------------------------------

# 7. Notifications

## Purpose

Keep students updated.

Types:

### Deadline Reminder

"Your registration closes tomorrow."

### Event Reminder

"Your workshop starts in 2 hours."

### Recommendation

"A new hackathon matches your interests."

### Application Update

"Your application status changed."

Features: - Mark as read - Notification preferences - Enable/disable
alerts

------------------------------------------------------------------------

# 8. Achievement / Badge System

## Purpose

Encourage participation.

Keep it simple, not gamified.

## Example Badges

### Explorer

Earned: Save 10 opportunities

### Participant

Earned: Attend first event

### Applicant

Earned: Submit 5 applications

### Community Member

Earned: Join 3 competitions

Display:

    🏆 Explorer
    🎯 Participant
    ⭐ Applicant

# Product Vision

Student Hub should combine:

-   LinkedIn profile building
-   Calendar organization
-   Notion-style tracking
-   Opportunity discovery

into one student-focused platform.

The experience should make students feel:

-   Organized
-   Prepared
-   Motivated
-   Connected
